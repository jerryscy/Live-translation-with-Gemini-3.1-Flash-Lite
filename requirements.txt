# `deepfilterlib` core requires the Rust toolchain to compile on
# platforms without prebuilt wheels (notably macOS Apple Silicon).
# After installing the requirements below, run *one* of the following
# to enable real DeepFilterNet v3 noise suppression for the VAD:
#
#     # Option A — install Rust first, then the wheel will build:
#     brew install rust              # or: curl https://sh.rustup.rs -sSf | sh
#     pip install -r requirements-vad.txt
#
#     # Option B — skip it entirely. The backend automatically falls
#     # back to a raw-audio RMS VAD that needs no extra deps.
#
# Either way the app fully works; with DeepFilterNet enabled, the VAD
# is much more robust to background noise.
